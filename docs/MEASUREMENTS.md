# Measured Results

All figures below are generated by checked-in scripts and should be treated as
emulator measurements, not theoretical performance claims.

## 2026-08-14: first RAM/TAP ECM playback

Input: `video/kling_20260815_dino_0.mp4`, first three frames sampled at 12 fps,
aspect-preserving 256x192 letterbox, temporal change penalty 5000.

Reproduce:

    python src/player/build_ram_demo.py ../video/kling_20260815_dino_0.mp4
    python src/player/validate_ram_demo.py
    python src/player/measure_decoder.py

Results:

- Python tests: 10 passed.
- Autostart TAP: 22,291 bytes.
- SVD sparse stream: 19,531 bytes for three frames.
- Final Fuse bitmap and attribute planes: exact 12,288-byte match.
- KEY decode: 344,020 T-states / 97.511 ms.
- SPARSE delta 1: 86,033 T-states / 24.386 ms.
- SPARSE delta 2: 87,450 T-states / 24.787 ms.
- Completed-frame interval after scheduler calibration: 85.707 ms then
  83.576 ms, converging on the 83.33 ms / 12 Hz target.

The earlier v0 row-run deltas measured 476,937 and 498,739 T-states. Sparse
absolute writes are approximately 5.6x faster for this sample because its
changes are highly fragmented. Retain row runs as an experimental format, not
the current high-performance default.

Remaining measurement work: longer-run cadence distribution, visible tearing,
scene-cut/keyframe behavior, and physical TS2068 timing.
